Prometheus soundpack: cleanup test build
=========================================

Thanks for testing! This is a test version of the Prometheus soundpack with its
scripting reorganised behind the scenes. It should sound and behave exactly like
the normal pack, except that some sounds that used to fail now play: mainly
messages containing quote marks, such as ship names in quotes, ship construction
announcements, Commpipe messages from named vehicles, and channel messages with
quotes in them.

How to use it
-------------
1. Unzip this into a NEW, empty folder, for example on your desktop.
   Don't unzip it over your normal Prometheus soundpack.
2. Open the mushclient folder inside it and run mushclient.exe.
   (changelog.html, next to it, lists what's changed.)
3. Connect and play as usual. Your normal soundpack and its settings aren't
   touched. This copy starts with default settings.
4. When you're done, just delete the folder.

What to report
--------------
- Any error message, especially when the world first opens. Copy the exact text
  if you can.
- Any sound that plays when it shouldn't, doesn't play when it should, or plays
  twice.
- Anything that behaves differently from the normal pack.

Please say roughly what you were doing and what the game said at the time.
